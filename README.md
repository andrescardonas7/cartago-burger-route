# 🍔 Cartago Burger Route

Una ruta interactiva de comida para descubrir los mejores lugares de hamburguesas en Cartago, Valle del Cauca.

## 📋 Descripción

Este proyecto presenta una experiencia web moderna y minimalista para explorar los mejores lugares donde comer hamburguesas en Cartago. Incluye un mapa interactivo, información detallada de cada establecimiento y una interfaz responsive.

## ✨ Características

- 🗺️ Mapa interactivo con ubicaciones de hamburgueserías
- 📱 Diseño responsive y mobile-first
- 🎨 Interfaz moderna y minimalista
- 🔍 Sistema de filtros y búsqueda
- 📍 Información detallada de cada establecimiento
- 🌙 Modo oscuro/claro
- ⚡ Carga rápida y optimizada
